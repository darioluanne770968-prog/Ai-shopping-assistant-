# 🛒 AI购物助手

智能全网比价浏览器扩展，帮助您找到最优惠的商品价格。

## ✨ 功能特性

### 核心功能：全网比价
- **多平台价格抓取** - 支持淘宝、京东、拼多多、天猫、苏宁、唯品会等
- **实时价格对比** - 同一商品在不同平台的价格对比
- **历史价格追踪** - 查看商品30/60/90天价格走势
- **优惠券聚合** - 自动搜索并显示可用优惠券
- **降价提醒** - 设置目标价格，到价通知
- **最低价检测** - 判断当前价格是否为历史最低

### AI智能分析
- **评论情感分析** - 分析真实用户评价，过滤刷单评论
- **产品优缺点总结** - AI总结商品的主要优缺点
- **购买建议** - 基于需求给出"值不值得买"建议
- **相似商品推荐** - 推荐性价比更高的替代品
- **商品真伪识别** - 分析店铺可信度、商品图片是否盗用
- **规格对比** - 不同型号/配置的智能对比

### 浏览器扩展功能
- **自动识别商品** - 打开商品页自动触发比价
- **悬浮比价窗口** - 不离开当前页面查看价格
- **快捷收藏** - 一键收藏到心愿单
- **购物车管理** - 跨平台购物车汇总
- **价格标注** - 在页面上直接标注价格信息

### 个人中心
- **心愿单管理** - 管理想买的商品
- **价格提醒管理** - 管理所有降价提醒
- **购买历史** - 记录比价和购买历史
- **省钱统计** - 统计累计节省金额
- **偏好设置** - 设置偏好平台、品类等

### 进阶功能
- **以图搜商品** - 截图/拍照搜索同款
- **链接转换** - 淘口令、短链接解析
- **分享比价结果** - 生成比价图分享给朋友
- **AI问答** - 询问"这款手机适合老人用吗"

## 📦 安装方法

### 开发者模式安装

1. 下载或克隆本仓库
```bash
git clone https://github.com/darioluanne770968-prog/Ai-shopping-assistant-.git
```

2. 打开Chrome浏览器，进入扩展管理页面
   - 地址栏输入：`chrome://extensions/`

3. 开启右上角的"开发者模式"

4. 点击"加载已解压的扩展程序"

5. 选择本项目文件夹

### 从Chrome商店安装（即将上线）

## 🚀 使用方法

1. **自动比价**：访问支持的购物网站商品页面，扩展会自动显示比价信息

2. **手动比价**：点击浏览器工具栏的扩展图标，查看详细比价信息

3. **设置提醒**：点击"🔔 提醒"按钮，设置目标价格

4. **收藏商品**：点击"❤️ 收藏"按钮，添加到心愿单

5. **以图搜商品**：点击"📷 以图搜商品"按钮，上传图片搜索同款

## 🛠️ 技术栈

- **前端框架**：原生JavaScript (ES6+)
- **样式**：CSS3 + CSS Variables
- **存储**：Chrome Storage API
- **图表**：Chart.js
- **扩展规范**：Manifest V3
